## Featured Project

### 🤖 [CloSim](https://github.com/JustSethHL/CloSim)

**A Unity-based simulator for FIRST Robotics Competition robots and games.**

CloSim expands on the MoSimBuilder ecosystem to provide a more complete environment for driving, testing, and experimenting with FRC-style robots.

**Built with:** `C#` · `Unity` · `Robotics` · `Simulation` · `UI/UX`

Some of the systems I've worked with include:

- Local multiplayer and split-screen gameplay
- Robot selection and configuration
- Driver-station and camera systems
- Multiple FRC game environments
- Keyboard and controller input
- Importable robot configurations
- Game-specific robot mechanisms and controls

### 🧩 Modular CloSim

Reworking CloSim so that robots can exist independently from the base game.

Instead of bundling every robot directly into CloSim, the goal is to create a system where users can install, remove, and select the robots they want to use.

**Focus areas**

`Modding` `Extensibility` `Architecture` `Unity` `C#`

### 📁 Smart Folder Manager

An experimental Windows utility that automatically organizes files placed into a designated sorting folder.

The goal is to combine structured naming rules with lightweight AI-assisted classification to make file organization require less manual work.
